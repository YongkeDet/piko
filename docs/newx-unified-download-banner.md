# 原生顶部下载进度与任务结果

适配目标：X 12.34.0-prod.01 / 312340001，arm64-v8a。
保留默认补丁 `NewX: Unified download notifications`，使用原版 APKM 重新修补。

下载进度保留同一个 X 原生顶部通知实例，只更新其文字。进度使用原生无限时长，
不会每秒重新入队、重置动画或变成一串短时弹窗。完成、失败和取消另生成一次结果，
沿用原生短时展示；当前结果真正退出后才展示下一条。

| 内容 | 主文字 | 次级文字 | 展示方式 |
| --- | --- | --- | --- |
| 普通下载 | 下载状态、百分比或等待状态 | 文件名、已传输/总大小、速度 | 下载期间固定展示 |
| 主页全部下载 | 已保存/已发现数量 | 照片或视频阶段、页数、跳过/失败数、速度或重试状态 | 同一条固定进度 |
| 下载成功 | 下载完成 | 保存文件、作者；批量任务显示汇总 | 单次原生成功提示 |
| 下载失败 | 下载失败或主页下载未完成 | 原因；批量任务补充停止阶段和累计结果 | 单次原生错误提示 |
| 主动取消 | 已取消 | 对应文件或本次主页任务的累计结果 | 单次普通提示 |

每个文件有独立任务 ID，长图合并使用独立 ID，主页批量任务也有独立 ID。
顶部一次展示一条进度，其他任务继续下载并维护自身状态；当前任务完成时按完成顺序
展示各自结果。已显示的结果不会被另一任务的进度或错误覆盖，也不会因为重复回调
再次入队。结果展示结束后恢复尚未完成的进度。

其他 X 原生提示出现时可暂时占用顶部位置。进度不会抢占其位置，排队的下载结果
继续保留。手动关闭进度后不会因定时更新重新弹出；任务完成的结果仍会展示。

顶部取消按钮只操作该条通知对应的任务。主页批量下载不再自动创建进度或结果
对话框，成员文件也不逐个显示完成提示，只在结束时汇总一次。任务使用 X 的当前
主页分页，请保持该主页在前台；切换标签页会终止该次分页任务并报告已保存结果。

沿用 X 原生主题、字体、圆角和通知样式。图片、视频、GIF、长图合并和重定向的
原生下载按钮共用此机制。系统通知栏进度和外部下载器的进度继续由其自身管理。

实现使用原生 Snapshot MutableState 和实际通知生命周期确认，不依赖估算的展示计时器。
旧目标没有经过本次原生适配验证，继续使用已有通知与进度路径。
