# Piko NewX Custom — 简体中文与功能补齐

适用于本次验证的 **X 12.34.0-prod.01 / 312340001，arm64-v8a，Android 10+**。用户已反馈上一版 `.1` 可正常使用。

[导入 Morphe 补丁源](https://morphe.software/add-source?github=YongkeDet/piko&name=Piko%20NewX%20Custom)

已添加 `YongkeDet/piko` 的用户刷新补丁源到 **3.10.0-custom-newx.2**，重新载入 `NewX:` 默认选择，再修补原始 APKM。

- **完整简体中文设置**：标题、说明、选项、编辑器、弹窗及媒体选择器已汉化，下载通知、合并图片和崩溃提示也使用中文。共 569 条 NewX 中文资源和 2 条共享设置资源，格式占位符经过检查。语言跟随应用/系统的简体中文设置。
- **分享链接去追踪参数**：在现有自定义分享域名功能中增加开关，清理 X/Twitter 帖子链接的追踪参数，保留功能参数及原始编码。
- **自定义链接处理**：新增 `NewX: Handle custom links`，默认注册常用镜像域名，可在补丁选项中修改。安装后需要到 **Android 应用信息 → 默认打开方式 → 打开支持的链接** 中启用。
- **外部下载器入口**：在 **Piko 设置 → 帖子与媒体 → 帖子内下载** 开启“显示外部下载器按钮”，通过系统分享面板发送当前媒体直链。开关默认关闭；接收应用需要支持链接下载。
- **更新日志入口**：新增 `NewX: Show changelog`，从 **Piko 设置 → 高级 → 更新日志** 打开本 fork 的发布说明。
- **自定义下载目录**：**Piko 设置 → 帖子与媒体 → 下载选项**，分别为图片、视频选择文件夹。

**验证结果**

- 54 项全选：54 成功、0 失败，APK 重建成功。
- 48 项默认选择：48 成功、0 失败，APK 重建成功。
- 73 项补丁测试和 254 项扩展测试通过，API 29、解析器及扩展描述符检查通过。
- 最终 APK 的 571 条中文设置资源全部存在、占位符一致；自定义链接桥接入口和 arm64 原生库通过静态检查。

旧版 73 项功能没有全部迁移：33 项有新版对应、14 项部分对应、25 项仍未迁移、1 项不适用于 NewX。新版更新日志不包含安装新补丁后自动弹窗；外部下载器采用系统分享面板，未复制旧版按包名发送帖子链接的流程。登录令牌、旧版关注列表等未找到可靠新版接口的项目按用户要求放弃本次迁移。详见[逐项迁移范围](https://github.com/YongkeDet/piko/blob/main/docs/newx-12.34-coverage.md)。
