# Piko NewX Custom — 按作者分别保存媒体

支持 **X 12.34.0-prod.01 / 312340001，arm64-v8a，Android 10+**。用户已实测 `.2` 正常。

[导入 Morphe 补丁源](https://morphe.software/add-source?github=YongkeDet/piko&name=Piko%20NewX%20Custom)

已添加本源的用户刷新到 **3.10.0-custom-newx.3**，重新修补原始 APKM。

新增 **Piko 设置 → 帖子与媒体 → 下载选项 → 按作者分别建文件夹**，默认开启：

- 图片保存到“所选图片目录/@用户名/文件”，视频保存到“所选视频目录/@用户名/文件”。用户名统一为小写，重复下载复用目录。
- 覆盖 Piko 普通下载、被接管的 X 内置下载及合并图片；同名文件的跳过、重命名、覆盖规则在各作者目录内生效。
- 识别转帖原作者；无法确认用户名时使用 `user_来源用户ID`，完全无法识别时使用 `unknown`。显示昵称不用于目录名。
- 开关可关闭并随设置备份。只影响之后的下载，不移动已有文件。外部下载器的保存位置由其自身控制。
- 保留完整简体中文设置和上一版的分享链接、外部下载器及更新日志功能。

验证结果：54 项全选与 48 项默认修补均零失败、APK 重建成功；73 项补丁测试与 255 项扩展测试全部通过。最终 APK 中三个下载入口、共享同步目录预留和 573 条中文资源均已确认。

旧版 73 项功能仍未全部迁移：**33 项新版对应、14 项部分对应、25 项未迁移、1 项不适用**。[迁移对照表](https://github.com/YongkeDet/piko/blob/main/docs/newx-12.34-coverage.md)。本次作者分目录交互仍需手机验证；没有对应旧 APK 做整包回归。
