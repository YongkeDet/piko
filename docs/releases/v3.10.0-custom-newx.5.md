# Piko NewX Custom — 主页一键下载与设置分类优化

适用于 **X 12.34.0-prod.01 / 312340001，arm64-v8a，Android 10+**。

[导入 Morphe 补丁源](https://morphe.software/add-source?github=YongkeDet/piko&name=Piko%20NewX%20Custom)

已添加本源的用户刷新到 **3.10.0-custom-newx.5**，重新载入默认选择后修补原始 APKM。
新增补丁 `NewX: Download all profile media` 默认启用。

在用户主页的 **媒体 → 照片** 页点击 **下载此主页全部图片和视频**，自动逐页遍历照片、
视频与 GIF，提供进度和取消，结束后恢复原来的标签页。保留默认启用的照片画廊和下载补丁，
并先在 **Piko 设置 → 下载与保存 → 保存位置与文件命名** 中选择图片、视频目录。

批量任务沿用目录、作者子文件夹、命名模板、画质与重名规则，最多同时排入四个文件；
画质为“每次询问”时使用最高可用画质。保持该页面在前台，且主页须提供照片和视频两个
标签页。任务对媒体去重，取消保留已保存文件；网络失败、分页停滞不会显示全部完成。
“全部”指 X 当前允许该账号通过分页返回的媒体。

设置重新整理为 **下载与保存、个人主页、时间线、内容过滤、帖子与互动、导航、外观、
高级** 八类；下载选项再细分为保存位置、下载方式、画质与重名、媒体选择窗口。
原有配置和备份取值保留，新界面与提示均提供简体中文。原来的顶部成功提示规则保留。

验证：**341 项测试通过；55 项全选、49 项默认修补均零失败并成功重建 APK**。
两份最终 APK 的主页父子组件绑定、原生分页、Success 复制路径、顶部成功提示和
594 条简体中文资源均通过静态检查。新批量流程的真实账号分页、文件提供器及取消交互
仍需手机实测；旧目标没有对应 APK 做整包回归。旧版 73 项功能的迁移缺口保持原状。
