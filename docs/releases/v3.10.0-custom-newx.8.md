# Piko NewX Custom — 固定底栏、自动刷新限制与下载进度

适用于 **X 12.34.0-prod.01 / 312340001，arm64-v8a，Android 10+**。

在 Morphe 刷新到 **3.10.0-custom-newx.8**，重新载入默认补丁选择，使用原版 APKM 重新修补并安装。
[导入补丁源](https://morphe.software/add-source?github=YongkeDet/piko&name=Piko%20NewX%20Custom)。

- **Piko 设置 → 时间线 → 禁止自动刷新新内容**：补上带视口游标的自动刷新路径，默认开启。保留首页/固定时间线首次加载、手动下拉刷新、翻页和主动更换筛选条件；沿用原有设置值。
- **Piko 设置 → 导航 → 固定底栏**：默认开启，修改后重启，滚动时保持手机主底栏显示。可与悬浮玻璃底栏同时使用，保留全屏/路由隐藏行为。
- **下载进度**：普通图片、视频和 GIF 在应用顶部显示传输数量、文件名、百分比、大小和速度；主页批量下载在原窗口增加字节进度条和速度。大小未知时显示已下载大小。完成、失败或取消后清理该项，成功仍只使用顶部横幅。

新增默认选中的 `NewX: Disable automatic content refresh`、`NewX: Fixed bottom navigation bar`。前者与原自动刷新补丁共用同一个设置开关。

继续保留自定义下载目录、作者子文件夹、主页分页及重试、玻璃底栏和八类中文设置。旧版 73 项功能仍未全部迁移。
合并长图显示分片下载进度及拼接/保存阶段；外部下载器、未重定向的原生下载使用各自状态反馈。

357 项测试通过；58 项全选、52 项默认修补均零失败并成功重建。两份 APK 各通过 101 项字节码/资源检查，613 条中文资源存在。

未操作用户设备。手机上的前后台切换、滚动、触控和进度布局需安装后试用。
