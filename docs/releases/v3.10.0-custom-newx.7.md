# Piko NewX Custom — 悬浮玻璃底栏

适用于 **X 12.34.0-prod.01 / 312340001，arm64-v8a，Android 10+**。

在 Morphe 刷新到 **3.10.0-custom-newx.7**，重新载入默认补丁选择，用原版 APKM 重新修补并安装。
[导入补丁源](https://morphe.software/add-source?github=YongkeDet/piko&name=Piko%20NewX%20Custom)。

新增默认选中的 `NewX: Floating glass navigation bar` 补丁。
安装后在 **Piko 设置 → 外观 → 悬浮玻璃底栏** 开启并重启，样式开关默认关闭。

- 圆角胶囊、原生背景模糊、半透明底色、细边框和阴影。
- 左右各 12dp，底部在系统手势安全区之外再留 8dp。
- 深浅主题自动适配，保留原生图标、未读角标、点击和自定义排序。
- 开启样式时移除底栏上方分隔线；关闭模糊仍保留悬浮外观及原生回退背景。

这是接近液态玻璃的 Android 效果，未实现 iOS 动态光学折射，范围限手机主底栏。
自定义下载目录、作者子文件夹、主页一键下载及分页恢复、顶部保存提示和八类中文设置继续保留。
旧版 73 项功能仍未全部迁移。

351 项测试通过；全选 56 项、默认 50 项均零失败并成功重建。
两份 APK 各通过 33 项底栏检查、30 项既有功能检查，605 条中文资源确认存在。
手机上的视觉、手势/三键导航、滚动与触控表现仍需安装后试用；未操作用户设备。
