# Piko NewX Custom — 修复主页批量下载分页失败

适用于 **X 12.34.0-prod.01 / 312340001，arm64-v8a，Android 10+**。

已添加本源的用户在 Morphe 刷新到 **3.10.0-custom-newx.6**，重新载入默认选项，
用原版 APKM 重新修补并安装。[导入补丁源](https://morphe.software/add-source?github=YongkeDet/piko&name=Piko%20NewX%20Custom)。

修复“下载此主页全部图片和视频”的两条已确认错误路径：空媒体标签页返回原生 Empty，
旧实现只识别 Success，因而等待超时；缓存中的历史网络失败也会让新任务立刻退出。

现在空标签页按有效空页处理，仍须确认服务端结束标记；暂时性失败每个逻辑请求最多尝试
三次，没有加载首屏时请求原生刷新，界面显示恢复进度。原生退避会继续等待，新限流或访问
拒绝会停止并给出原因。单条异常媒体计入失败数并继续处理后面的内容。

失败提示区分网络、超时、访问受限、限流、重复游标、标签变化与媒体状态读取失败，
并显示停止阶段和累计读取页数。下载入口仍在 **用户主页 → 媒体 → 照片**；
目录、作者子文件夹、命名、画质、去重、取消、顶部成功提示及八类中文设置保留。

**348 项测试通过；55 项全选、49 项默认修补均零失败并成功重建 APK。**
两份最终 APK 各通过 30 项字节码/资源检查，确认空页分支、原生刷新入口、真实游标字段链、
顶部提示和 603 条中文资源。修复后的真实账号分页仍需手机复测，没有将未验证版本加入支持范围。
