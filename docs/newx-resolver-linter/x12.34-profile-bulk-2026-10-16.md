## 实际修补失败：分页器捕获与组件 getter 混淆

失败构建源 `855ca0da71a7e1af836cf55ca1a93a58477701d7`，
[CI 38829997185](https://github.com/YongkeDet/piko/actions/runs/38829997185)。
当时的 `patches-3.10.0-custom-newx.5.mpp` 为 8,981,367 字节，
SHA-256 `d6dbcce4e53198156fa62bb3d86a6391bdeb705e9c7cfa7bcc6c09ea35a898ce`；
NewX 扩展 SHA-256 `b1096b7a5051c679dd346ff22bc8013eb94d5f4081768d3c58d27f280c3c823a`，
共享扩展哈希与基线相同。

使用 Java 21.0.12.1、官方 Morphe Desktop 1.18.1，JAR SHA-256
`1b506ab5f03d16a2f65026d5e0e1910d01fc1e2152f21eaeb44ed2f30856597b`。
当前源与 source-provenance 完全相同，工作树源码干净；未使用强制兼容。
命令（路径参数指向上述确定文件）：

```sh
PATCHER_JAVA=JAVA21 MORPHE_CLI_JAR=morphe-desktop-1.18.1-all.jar \
PATCHER_OUTPUT_APK=build/newx-bulk-all.apk \
./patch-twitter.sh ORIGINAL.apkm --all-newx --unsigned \
  --continue-on-error --disable-purge --bytecode-mode FULL
```

55 项选择中 54 项应用成功，新增的 `NewX: Download all profile media` 失败：

```text
Expected exactly one NewX bulk URT host, found 3:
[Lcom/x/urt/a0;, Lcom/x/urt/paging/bottom/b;, Lcom/x/urt/paging/bottom/d;]
```

完整异常保存在 [错误文本](x12.34-profile-bulk-host-failure.txt)，原始修补报告见
[JSON](x12.34-profile-bulk-host-failure.json)。虽然 CLI 在 continue-on-error 模式下重建了 APK，
仓库 wrapper 根据 failedPatches 正确以失败结束。该失败包未发布。

原因：初始谓词只检查 URT 范围内是否存在底部分页器字段，两个协程内部类也捕获同一对象，
因此得到三个候选。cardinality helper 正确拒绝歧义。通用 linter 与 helper 均未修改；
不属于 linter 错误、helper 错误、APK 版本变化或资源缺失。

修正后，组件必须提供无参数、返回原生 paging interface 的实例 getter，且 getter 读取该
底部分页器字段。SuspendLambda 的带参数 invokeSuspend、Function0 返回 Object 的捕获方法
均不能充当该组件。未按本次混淆类名排除协程。

回归夹具位于
`patches/src/test/kotlin/app/crimera/patches/newx/misc/mediatab/ProfileBulkHostResolverTest.kt`，
通过真实的 `resolveBulkTimelineHost` 入口验证三种重命名、两种协程捕获、零参数捕获、
无结果与两个真实组件的歧义。预期只有具备 getter 契约的组件可匹配；真实歧义继续失败。
这隔离了组件谓词的变化，故原因归属具有直接证据。

## 调用链复核与功能边界

在原始 smali 中核对 profile renderer 把 `A(tab, sorting)` 返回的**子 URT 组件**交给时间线 UI。
回调捕获的是这个子组件；标签选择控制器属于它的组合父组件。
实现因此在原生子组件创建/缓存返回点绑定 child → owner，并以实例身份查找父控制器。
读取媒体时访问当前选中的子组件状态流。原生 Success 复制时保留同一个列表的状态会继承其
过滤前快照；新列表自己的快照保留，避免将不同用户的空过滤结果混用。

同时核对 NO_CURSOR、明确终止、失败、加载中、重复游标、嵌套模块及最后一页处理。
详细功能说明、入口、设置分类与原生语义锚点见
[实现说明](../newx-profile-bulk-download.md)。
