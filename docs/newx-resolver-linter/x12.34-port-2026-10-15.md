# X 12.34.0-prod.01 migration incident

Target: `com.twitter.android`, version `12.34.0-prod.01` / `312340001`, production APKM,
arm64-v8a, Android 10+. Input SHA-256:
`016a7eb2b6d8e2d6410da7f3c60e1bb46b002f6fedd797e366b068fb2897682b`.

The reported Manager 1.35.0 / Patcher 1.15.1 failure selected legacy patches. Legacy settings
require `res/xml/settings_root.xml`, which this app no longer contains. Removing this check
does not port the old view/model contracts. The new bundle packages NewX patches separately.

The video model uses outlined object and integer StringBuilder helpers, not adjacent label/field
loads. Its native player configuration consumes PreferredHeight; the chosen native format height
then supplies both Media3 constraints. The highest-resolution setting constructs a high preferred
height (half MAX_VALUE avoids subtraction overflow) and bypasses only the native division by two
for the minimum height. Disabled settings keep the original configuration and division. R8 merges
unrelated coroutines into switch arms which reuse the divisor register. The previous linear lookup
examined writers from other arms; the final resolver follows actual CFG predecessors and requires
that every reaching integer definition be two. It follows the shared-setter GOTO as well.

The reply-bar renderer and timeline save method reach switches before liveness can discover fresh,
unused registers. Their calls now stage arguments in explicitly reserved locals. The scroll capture
helper lives on the original component so private field access remains legal. An unloaded timeline
skips only the map write and preserves native bookkeeping. The fixtures exercise dense register
frames, switch boundaries, branch relocation, invoke/result adjacency and the original continuation.

These failures were resolver/emission logic and APK contract drift, not linter or cardinality-helper
failures. No generic linter change or weakened cardinality check was used. CI rounds 8 and 9 caught
malformed regression switch payload setup; round 10 fixed the fixture construction before the next
APK test. The resulting real-APK failure was then fixed with the CFG-aware video resolver.

## Validation boundary

The current NewX suite passes patch application and rebuilding. This is not a claim that all 73
legacy features were ported. The [coverage matrix](../newx-12.34-coverage.md) identifies 31 legacy
entries with a NewX counterpart, 12 partial counterparts, 29 not yet migrated, and one redirect
patch not applicable to an input which is already NewX.
No physical device, login session or media download has been exercised. Existing older-target
paths are retained; this session only has the supplied 12.34 APKM for real APK validation.
