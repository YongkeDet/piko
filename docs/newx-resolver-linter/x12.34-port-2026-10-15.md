# X 12.34.0-prod.01 migration incident

Target: `com.twitter.android`, version `12.34.0-prod.01` / `312340001`, production APKM,
arm64-v8a, Android 10+. Input SHA-256:
`016a7eb2b6d8e2d6410da7f3c60e1bb46b002f6fedd797e366b068fb2897682b`.

The reported Manager 1.35.0 / Patcher 1.15.1 failure selected legacy patches. Legacy settings
require `res/xml/settings_root.xml`, which this app no longer contains. Removing this check
does not port the old view/model contracts. The new bundle packages NewX patches separately.

- Upstream NewX base: `df8a1ec73a39f2b316417135694f357cd7155340` from `crimera/piko` `x-lite`.
- Initial source: `4700d3e5e80b02342091a98cdd1eb9ad3dbb2db2`.
- [Build, tests and linters](https://github.com/YongkeDet/piko/actions/runs/38708166233).
- MPP SHA-256: `18711654c21a11c3b724f066db55f1bdb41c28d9b74fd8bb5a9fa17eed802651`.
- Extensions came from the same source/build; Android `classes.dex` was checked before upload.
- Validation used Morphe Desktop 1.18.1, through `patch-twitter.sh` with the exact original APKM,
  `--all-newx --unsigned --continue-on-error --disable-purge --bytecode-mode FULL`. No force flag.
- Output: `newx-all-baseline.apk`; report: `x12.34-baseline-errors.json` in this directory.
- 49 named patches selected: 43 applied, 6 failed. APK rebuilding alone is not a pass:
  `patch-twitter.sh` also rejects a non-empty failed-patch list.

## Contract drift found

| Patch | Exact target evidence | Cause |
| --- | --- | --- |
| Highest media quality | Audio ID regex now resides in a static source helper; the old onTracksChanged log marker is absent | APK contract drift |
| Hide post reply bar | Every 4-bit register is live at the immersive action-row call | Register pressure at the chosen injection site |
| Canonical URLs | Card navigation adds a trailing boolean argument | APK ABI drift |
| Twitter branding | The refresh renderer and home header consume the shared `ic_vector_x` drawable; procedural xlogo classes are absent | Product implementation changed |
| Timeline position | The map write is followed by cache/visibility bookkeeping | APK control-flow drift |
| Theme | Static factories call a default-mask wrapper which delegates to the concrete color-scheme constructor | Constructor graph changed |

The three additional post policies were built in source
`d5da2465a59ed394a19ac3725855a5090f40e298` ([CI](https://github.com/YongkeDet/piko/actions/runs/38709256831)).
MPP SHA-256: `2ae36b2ca0462b26e59bba1ebca4a47bd95b1a05795f879d561bde8ee041ff98`.
Full errors are in `x12.34-post-policy-errors.json`. They exposed two more contracts:
R8 interleaves two boolean labels through an outlined append helper, and the serialization
constructor has more than one normal return. These are resolver/emission issues, not linter failures.
